# HD2 击杀卡

本地单页工具。选定武器和战备、选定一名《绝地潜兵 2》敌人，并可选行星环境后，给出怎么打、弱点在哪、哪种伤害类型更有效。

## 用法

配装栏有五个空位：主武器、副武器、手雷、支援武器、最多四个战略。每一格都可以空着。一件不填、只填一件、或填满，都用同一套结算。

- 一件装备都没有：卡片给出通用弱点、伤害类型和一句打法，不出现「你的装备」。
- 填了装备：在打得动的部位上比较这些装备，最多列出三件，并说明先用哪一件打哪。

敌人覆盖导入结果里的全部《绝地潜兵 2》单位，包含轻型杂兵。第一代阵营 `Cyborg Legion` 排除。

环境可以不选。不选时按没有天气、没有阴霾结算。可以手动勾选天气和阴霾等级，也可以选一颗星球，用该星球当前的天气和阴霾。

## 击杀卡

选定敌人后显示。顺序固定。

**打法。** 一句话。没带装备时，指向护甲最低的致命部位，并带上倍率高于 1 的伤害类型。带了装备时，写成「用哪一件的哪个组件，打哪个部位」。数字齐全时写成「大约 N 发」。主句使用最有利的一档：正面（小于 25°）、贴脸、爆炸内圈；若勾了酸雨，主句用减过护甲后的结果。

**条件。** 只在结果发生变化时出现。变化指：由打得穿变成打不穿、大约发数改变、或能不能打到后一部位发生改变。比较对象是主句那一档。需要比较的情况：

- 另外三个入射角：26°–60°、61°–80°、81°–90°
- 投射物在 25 米和 50 米
- 爆炸外圈中点
- 光束在最大射程
- 酸雨结束后护甲恢复

**环境。** 没选环境时不出现。写出当前条件，以及实际参与计算的数字。

**伤害类型。** 只处理火焰、电弧、酸液、气体。倍率高于 1 写「更有效」，在 0 和 1 之间写「抗性」，等于 0 写「免疫」。等于 1 或缺失的不写。

**弱点。** 最多三个部位。排序：致命优先，然后护甲从低到高，再然后生命从低到高。每行包含部位名、护甲、是否致命；有耐久才写耐久。标成可打碎外甲时，加一句「先打碎外甲，伤害不进里面」。没有部位数据时，这一段改为「部位暂缺」，打法只保留总生命和伤害类型。

**你的装备。** 至少选了一件才出现，最多三条。能瞄准的写「装备、组件、部位、原因」。轨道炮和空袭不写具体部位，只写伤害类型，以及穿甲够不够躯干。躯干指部位 id 或英文名包含 `torso` 或 `body` 的部位；有多个时取生命最高的那个。没有这样的部位时，不写躯干穿甲对比。打不穿的不进前三，末尾一行写数量。

**依据。** 默认收起。包含本次用到的规则、缺了哪些字段、wiki 页链接、导入日期。同一字段 HD2Tool 和 wiki 不一致时，两个值都写在这里。

界面是文本，不打包游戏图片。部位名先查中文对照表，没有条目的保留英文。

## 结算

纯函数：输入敌人、配装、环境，输出上面这张卡。页面上不放角度和距离滑条。

单发伤害按这个顺序计算，全部乘完后只向下取整一次：

1. 酸雨生效时，部位护甲减 1，最低为 0。后面的穿甲对比、穿透表和外甲三倍门槛都用这个护甲。
2. 取这一档的穿甲。投射物按入射角四档取值。爆炸只有一个穿甲，不看角度；外圈再减 1，最低为 0。光束用一个穿甲。
3. 距离衰减同时乘到标准伤害和耐久伤害上。
4. 穿甲高于护甲为满伤，相等乘 65%，低于则为 0。
5. `标准伤害 × (1 − 耐久) + 耐久伤害 × 耐久`。耐久缺失时不做混合，若标准伤害存在就只用标准伤害，并在依据里记一笔。

大约发数为 `ceil(部位生命 / 单发伤害)`。单发伤害为 0、部位生命缺失、或护甲值不是 0 到 10 的整数时，不写发数；最后一种同时视为打不穿，也不查穿透表。

### 入射角

| 档位 | 角度 |
| --- | --- |
| 正面 | 小于 25° |
| 小角度 | 26°–60° |
| 大角度 | 61°–80° |
| 极限角度 | 81°–90° |

数据里只有一个穿甲值时，四档共用，条件里不出现入射角。

### 距离衰减

投射物使用 wiki 的简化公式，不模拟游戏内弹道。依据里写明它和游戏内模拟大约差 2%–4%。

```
D = 0.0004712389 × size² × Cd / mass
Lp = 1 − 0.75 × (1 − e^(−2 × D × x))
```

`size` 单位是毫米，`mass` 单位是克，`Cd` 是阻力系数，`x` 是米。`Cd` 为 0 时 `Lp` 为 1。计算点是 0 米、25 米、50 米。缺尺寸、质量或阻力系数时，不写距离行。

爆炸：

- 内圈：伤害不衰减，穿甲不减。
- 外圈：穿甲减 1。中点取内外半径的正中，`x = 0.5`。慢衰减 `Le = 1 − x²`，快衰减 `Le = 1 − x`。
- 验算点另算目标距爆心 20 米、内圈 10 米、外圈 25 米：`x = 2/3`，快衰减为 1/3，慢衰减为 5/9，同时穿甲减 1。

缺内径、外径或衰减类型时，仍给出外圈穿甲减 1 的打不穿与否，不写伤害百分比。

光束只用于带了光束衰减字段的武器：

- `d ≤ fstart` 时倍率为 1
- `fstart < d ≤ range` 时，`Lb = 1 − (1 − bf) × (d − fstart) / (range − fstart)`

主句用衰减起点，条件里只在最大射程的结果有变化时出现。

### 一发打穿

先判断这一发能不能打中当前部位。不能打中就不穿透。

能打中之后，用穿透表判断能不能穿过当前部位。表的键是护甲等级和耐久档。酸雨先改护甲，再查表。等级对应关系：

| 护甲值 | 等级 |
| --- | --- |
| 0 | 无甲 |
| 1 | 极轻 |
| 2 | 轻 |
| 3 | 中 |
| 4 | 重 |
| 5 | 坦克 I |
| 6 | 坦克 II |
| 7 | 坦克 III |
| 8 | 坦克 IV |
| 9 | 坦克 V |
| 10 | 坦克 VI |

穿透表只收录有公开行的等级。当前公开行是：

| 目标护甲 | 耐久 0–24% | 25–75% | 76–100% |
| --- | --- | --- | --- |
| 无甲 | 穿甲 ≥ 2 | 穿甲 ≥ 3 | 穿甲 ≥ 4 |
| 极轻 | 穿甲 ≥ 4 | 穿甲 ≥ 5 | 穿甲 ≥ 5 |

表里没有的等级不估算，不写穿透行。穿过之后，下一部位使用的穿甲等于原穿甲减去耐久消耗：0–24% 减 2，25–75% 减 3，76–100% 减 4。再按穿甲三档和耐久混合结算下一部位。没有标明后一部位时，不写穿透行。

可打碎外甲有单独生命，溢出不进内部。外甲还在时，同一发要打到内部，穿甲必须大于或等于外甲护甲的三倍，并且穿透表也通过。护甲为 0 时三倍门槛为 0。有一道不通过，发数就等于打碎外甲的发数加上再打死内部的发数。

爆炸对主生命只结算一次。爆炸的发数取单个最合适部位，不把多个部位的伤害相加。最合适指：能打穿的致命部位里发数最少的；没有致命部位时，取能打穿且发数最少的部位。

穿透造成的速度损失不乘进伤害。

### 装备排序

离子风暴生效时分成两组：手上的武器在前，需要新呼叫的战略在后。主武器、副武器、手雷算手上的。支援武器和战略算需要呼叫的。风暴中的主句只从手上的武器里选；没有手上的武器时，主句仍给出战略，并标明「风暴间歇才能呼叫」。

每一组内部的排序：

1. 能打穿致命部位的在前。
2. 大约发数少的在前。写不出发数的排在写得出发数的后面。
3. 单发伤害高的在前。
4. 仍相同则按空位顺序：主武器、副武器、手雷、支援武器、战略一到四。

前三名之外、且对所有部位都打不穿的，计入「打不穿」的数量。缺少战斗数据的不参与排序，单独写「缺少战斗数据」。

没带装备时，打法句子选用致命且护甲最低的部位；护甲相同则取生命更低的。没有致命标记时，取护甲最低的部位。

## 环境

环境指行星天气和阴霾。任务修饰符不在这一版里。

几种天气可以同时生效。酸雨的护甲只减一次。火焰龙卷生效时同时套用炎热；两处冷却修正只乘一次。

| 条件 | 对击杀计算的影响 |
| --- | --- |
| 酸雨 | 敌人护甲减 1，最低为 0。主句按风暴正在发生。护甲恢复后结果有变化才写条件行 |
| 严寒 | 射速按 90% 计算。热量武器冷却时间变为原来的 2/3。单发伤害不变。射速字段是每分钟发数，有该字段时另写大约秒数：`发数 / (每分钟发数 / 60 × 0.9)`。没有基础冷却秒数时只写 2/3，不写冷却秒数 |
| 炎热 | 热量武器冷却时间变为原来的 4/3。没有基础冷却秒数时只写 4/3。不改单发伤害，不改发数 |
| 火焰龙卷 | 套用炎热。龙卷火焰不计入发数。环境行写明敌人视野下降 |
| 离子风暴 | 不改枪的发数。战略降到手上武器之后，并标明风暴期间不能新呼叫 |
| 岩浆、陨石 | 不计入发数，只在环境行说明场上有额外伤害 |
| 暴风雪、沙尘暴、暴雨、浓雾、地震 | 不改发数。环境行分别写能见度中等下降、大幅下降、下降、轻微下降、瞄准会被震停 |

阴霾等级的数字：

| 等级 | 写入环境行的数字 |
| --- | --- |
| 无、轻 | 不因阴霾增加环境行 |
| 中 | 鹰式再装填加 20% |
| 重 | 鹰式再装填加 30%，拾取弹药减半 |
| 源头 | 与重相同，另写增援数减 20% |

这些百分比不换算成单发伤害。配装里有鹰式战略时才写再装填。

选星球时，请求 `https://api.helldivers2.dev` 的星球接口，请求头 `X-Super-Client: hd2-kill-card`。`hazards[].name` 转成小写并去掉首尾空格后，映射到上表。映射表放在 `data/environment.json`。认不出的名称原样显示，不编效果。阴霾等级来自导入时根据 wiki「The Gloom」页生成的星球表；接口没有等级时用这张表。

开发服务器把 `/hd2-api` 转发到该接口，并补上请求头。静态打开时浏览器直连。直连或转发失败时，手动勾选仍可用；若有上次成功的星球缓存，可以继续选，卡片写缓存时间。

## 页面

宽屏左侧选择、右侧击杀卡。窄屏先选择、卡片在下。

左侧从上到下：五个配装空位，中文名、型号、英文名、外号都能搜；敌人搜索和阵营筛选；环境。环境里可以不指定、选缓存或在线的星球、或手动勾选天气和一个阴霾等级。

换装备、敌人或环境时立刻重算，不设单独的计算按钮。

## 数据

运行时只读本地 JSON，不再请求 wiki。导入脚本生成这些文件：

| 文件 | 内容 |
| --- | --- |
| `data/equipment.json` | 装备、组件、四档穿甲、两种伤害、射速、弹道、爆炸半径、衰减类型、光束字段、是否热量武器、是否鹰式、是否需要呼叫 |
| `data/enemies.json` | 敌人、阵营、总生命、四种伤害倍率、部位、后一部位、是否外甲、是否致命、wiki 页 |
| `data/environment.json` | 天气映射、阴霾星球和等级、天气与阴霾的数值效果 |
| `data/part-names.zh.json` | 部位中文对照 |
| `data/meta.json` | 导入日期、游戏版本（能取到才写）、各来源 URL |

中文名、型号、外号来自 HD2Tool 的 `catalog.json` 和 `community-aliases.json`。四档穿甲、伤害、弹道、爆炸、部位和穿透表来自 wiki 解码数据。阵营、总生命和四种倍率来自 wiki 敌人表 `game = Helldivers 2`，并排除 `Cyborg Legion`。

同一字段两边都有且数值不同：计算用 wiki，依据里并列两个值。只有 HD2Tool 有的组件保留，缺的战斗字段留空。对不上中文名的 wiki 装备用英文名，仍可搜索。

部位中文对照至少包括：头、腿、臀、躯干、臂、散热口、肉、囊、尾、翼、眼、口、腹部。

## 架构

- Vite 加 TypeScript。界面直接调用结算函数。
- `src/kill.ts` 导出结算函数，不读网络，不读 DOM。
- 导入脚本只在更新数据时运行，不属于页面运行路径。
- 星球缓存放在 `localStorage`。配装选择也放在 `localStorage`，刷新后还在。
- 第一版不设账号、服务端存储和图片打包。

## 异常

| 情况 | 卡片 |
| --- | --- |
| 没选敌人 | 提示先选敌人，不计算 |
| 没有部位 | 保留总生命和伤害类型，弱点写「部位暂缺」 |
| 装备缺少战斗数据 | 留在列表中，写「缺少战斗数据」 |
| 缺弹道、半径或后一部位 | 对应行不出现，依据写明缺的字段 |
| 接口失败 | 手动环境可用；用缓存时写缓存时间 |
| 未知天气名 | 显示原文，不改数字 |
| 两来源数值冲突 | 计算用 wiki，依据并列两值 |

## 验算

结算测试要锁定这些结果：

1. 标准伤害 95、耐久伤害 23、耐久 30%、穿甲高于护甲、无衰减，单发为 73。
2. 穿甲等于护甲时先乘 65%，再混合耐久，再向下取整。穿甲低于护甲时单发为 0。
3. 四档穿甲里只有打不穿或发数变化的角度出现在条件里。四档穿甲相同时没有入射角条件。
4. 阻力系数为 0 时，0 米、25 米、50 米的衰减倍率都是 1。内圈 10 米、外圈 25 米、距爆心 20 米时，快衰减为 1/3，慢衰减为 5/9，外圈穿甲减 1。
5. 无甲、耐久 80% 的穿透门槛是穿甲大于或等于 4。通过后，下一部位的穿甲再减 4。轻甲、中甲、重甲和各级坦克不产生穿透行。
6. 酸雨把护甲 2 降为 1 后，穿甲 2 从 65% 变为满伤。酸雨结束后的发数不同才出现条件行。
7. 离子风暴不改变手上武器的发数，战略排在这些武器后面。
8. 配装为空时仍有弱点和伤害类型，没有「你的装备」。
9. 火焰龙卷和炎热同时勾选时，热量冷却只按 4/3 计算一次。
10. 阻力、半径或后一部位缺失时，主句仍能给出正面贴脸的穿甲结论，对应条件行不出现。

## 范围外

角度和距离滑条、游戏内逐帧弹道、穿透速度损失、把多部位爆炸伤害相加、岩浆陨石和龙卷的伤害计入发数、任务修饰符、装备图片、账号。
